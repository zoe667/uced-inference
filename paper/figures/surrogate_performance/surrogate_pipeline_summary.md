# Current surrogate-validation pipeline

This note records the implementation used for the Results subsection. It is tied to the outputs in `experiment/runs_2016_noEI` and `experiment/runs_2021_new`.

1. `experiment/04_build_surrogate.jl` is the current production GP-development script. It makes a deterministic, loss-stratified 80/20 development/test split inside `validate_metamodel`. The held-out rows are saved in `master_data_split.json` with role `independent_reporting_only`.
2. Kernel selection is performed only on the development set. The candidates are `SEArd`, `Mat32Ard`, and `Mat52Ard`; nested cross-validation selects the family. Both current runs select `Mat32Ard`.
3. After kernel selection, `run_fixed_kernel_ard_screening` refits the selected family in five development folds. A dimension is marked candidate-inactive when `log(length scale) >= 4.0 - 0.1` in at least `ceil(0.8 * 5) = 4` folds. Thus the implemented rule is the stated 4/5 upper-bound rule, with a 0.1 log-scale numerical tolerance.
4. `reduce_dimensions_if_needed` refits the GP on the retained dimensions, using the same development rows, fold assignments, and selected kernel family. The production script saves both the full and reduced development fits but evaluates only the selected reduced model on the test set.
5. `experiment/04b_active_parameter_robustness.jl` is the formal development-only robustness suite. It performs nested cross-fitted full-versus-reduced ablation, outer-fold selection-stability checks, and ARD-bound sensitivity. The current 2021 package passes its cross-fitted ablation but is flagged for review because doubling the length-scale ceiling adds two retained dimensions. The 2016 package passes the saved checks.
6. `experiment/05_surrogate_search.jl` loads `trained_metamodel_reduced.jld2`, creates a dense stratified-LHS pool over the retained ex-ante domain, and predicts the loss surface offline. It contains no EI, Bayesian optimization, feasibility GP, or admissibility filtering. Its dense predictions are not validation data and are not used in the accuracy metrics reported here.
7. `paper_assets/noEI/surrogate_performance/build_surrogate_results_package.jl` is reporting-only. After selection is complete, it applies the saved full and reduced models to the same frozen held-out UCED rows, inverts the saved target standardization to the original aggregate-loss scale, and exports the comparison. It verifies that the regenerated reduced predictions exactly match the predictions saved by 04.

The similarly named `experiment/04_validate_metamodel.jl` is an older implementation that evaluates the test set during the reduction workflow. It is not the implementation used for the current results package.
